# Production audit: https://voxelport.in (2026-11-20)

Branch `production-verification` (from `main` = what is live). Everything below was verified again in this pass; earlier findings were not assumed. Tools: `node scripts/audit-live.mjs https://voxelport.in --external` (new, read-only), `curl`, Lighthouse 12 (mobile preset) on the local production build, a browser at desktop and 375 px width, and the GitHub and Discord APIs.

## Phase 1: does production match the repository?

**Yes.** All 37 sitemap pages served by `voxelport.in` are byte-for-byte (whitespace-normalised) the same static HTML as a fresh build of `main`. Every page returns 200, has a unique title and description, a canonical equal to its own URL, Open Graph and Twitter tags, parseable JSON-LD and no `noindex`. An unknown URL returns 404. 48 internal links and 19 external links all resolve (Instagram, LinkedIn and discord.gg were skipped: they block bots; the Discord invite was checked through Discord's API instead).

Resolved question: the site's Discord invite `JAUfmey2fP` is **valid** (Discord API returns the invite, created by the maintainer); the other one in the maintainer's notes, `2wJbCPwP4r`, is **expired** ("Invite is expired"). No change needed on the site.

## Verified OK (no change needed)

- **Windows guidance (Phase 2):** no page recommends turning off Smart App Control, Defender or antivirus (grep of `src`, `scripts`, built HTML; `verify` fails if it returns). The text explains why an unsigned installer warns, links the official GitHub release, shows the SHA-256 and the `Get-FileHash` steps, and offers safer options. Not tested on a real Windows 11 machine with Smart App Control (this PC cannot run local installers); the wording follows the maintainer's own `CODE_SIGNING.md` and Microsoft's documented behaviour (SmartScreen per-file prompt; Smart App Control blocks unsigned installers without override).
- **Download page (Phase 3):** all release facts come from `src/release.js`, checked against the GitHub release v2.0.0 assets (installer 3,279,649 bytes, SHA-256 `1ea882d4…16dc`, released 2026-11-18) and the live Android feed (1.0.0, versionCode 22, 54,638,754 bytes; the served APK hashes to the feed's SHA-256). Android's release date is not published anywhere and is omitted; no beta exists. Download links return 200 on production; the preview serves the same links.
- **Comparison (Phase 5):** sourced, dated 2026-11-20, "Not checked" where unverified; playit.gg pricing/games and agent license and ngrok plan facts re-read from their own pages.
- **Status APIs (Phase 6):** `relay`, `eu`, `la` and `direct:26499` `/api/status` answer 200 with `access-control-allow-origin: *`; the browser page loads live counts and pings; requests time out after 8 s; empty/failed states are accurate (tested by blocking requests). 375 px layout has no horizontal scroll; the static HTML explains the page before data loads.
- **SEO (Phase 7):** titles, descriptions, canonicals, Open Graph, Twitter, JSON-LD (no ratings or reviews), `robots.txt` (Allow, sitemap line), `sitemap.xml` (37 URLs), 404 behaviour, preview exclusion (`X-Robots-Tag: noindex`, meta noindex, `Disallow: /` on preview builds).
- **Vercel (Phase 8):** `vercel.json` is needed (clean URLs, `www` redirect, `/dl/` rewrite to the update origin, security headers/CSP, immutable asset caching). No catch-all rewrite. HTTPS and HSTS present, `http` redirects (308). No functions, no middleware, no paid features, no environment variables or secrets.
